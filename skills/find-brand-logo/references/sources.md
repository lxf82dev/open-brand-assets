# Source adapters

The helper searches these collections; it does not mirror them. All source requests are public and unauthenticated. A source failure is reported separately from a successful search with zero matches.

| Source | Lookup | Coverage and constraints |
| --- | --- | --- |
| [Open Brand Assets](https://github.com/lxf82dev/open-brand-assets) | Local `catalog.json`, otherwise `https://raw.githubusercontent.com/lxf82dev/open-brand-assets/main/catalog.json` | Complementary brands and official variants with hashes, retrieval dates, usage notes, and original URLs. MIT applies to our code; brand assets keep their own rights. |
| [SVGL](https://github.com/pheralb/svgl) | `https://api.svgl.app/` | Full-color logos, wordmarks, theme variants, and `brandUrl` where supplied. MIT repository license; inspect brand terms separately. |
| [Lobe Icons](https://github.com/lobehub/lobe-icons) | GitHub `master` tree, `packages/static-svg/icons/*.svg` | AI providers and models. Results link to exact SVGs at the returned commit SHA. MIT repository license. |
| [Simple Icons](https://github.com/simple-icons/simple-icons) | GitHub `develop` tree, `icons/*.svg` | Monochrome brand icons. CC0 collection; individual brand rights and restrictions still apply. Read the matching entry in `data/simple-icons.json` for guidelines/source/license metadata. |
| [theSVG](https://github.com/glincker/thesvg) | GitHub `main` tree, `public/icons/<brand>/*.svg` | Broad brand and cloud-service coverage. Results link to exact variants at a commit SHA. MIT repository license. |
| [Gilbarbara Logos](https://github.com/gilbarbara/logos) | GitHub `main` tree, `logos/*.svg`, plus pinned `logos.json` | Optimized developer/DevOps logos. Display names and shortname aliases from metadata. CC0-1.0 project; third-party brand rights remain separate. |
| [Vector Logo Zone](https://github.com/VectorLogoZone/vectorlogozone) | GitHub `main` tree, `src/content/logos/<brand>/*.svg` | Standardized icons, tiles, and horizontal marks. AGPL-3.0 is the **website code** license. Logos remain their owners' property; upstream places its modifications in the public domain. Read its README and each brand's official terms. |
| [Devicon](https://github.com/devicons/devicon) | GitHub `master` tree, `icons/<tool>/*.svg`, plus pinned `devicon.json` | Programming languages and developer/design tools. Supports `altnames` such as `arm64`. MIT project license; vendor rights remain separate. |
| [selfh.st Icons](https://github.com/selfhst/icons) | GitHub `main` tree, `svg/` with PNG-only fallback from `png/`, plus pinned `index.json` | Self-hosted services and other applications. CC-BY-4.0 collection: retain the returned selfh.st contributor attribution and license link, plus any brand-specific conditions. |
| [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons) | GitHub `main` tree, `svg/` with PNG-only fallback from `png/` | Dashboard, homelab, and app/service logos. Apache-2.0 project; preserve required notices and check vendor terms separately. Only its own committed assets are indexed, excluding its external federated catalogs. |
| [Cryptocurrency Icons](https://github.com/spothq/cryptocurrency-icons) | GitHub `master` tree, `svg/{black,color,icon,white}/`, plus pinned `manifest.json` | Currency names and symbols, including Bitcoin/BTC. CC0-1.0 project. Verify currency identity; generic placeholder artwork is not evidence of an actual brand match. |

`search --source <name>` narrows the search; names are `ours`, `svgl`, `lobe`, `simple-icons`, `thesvg`, `gilbarbara`, `vectorlogozone`, `devicon`, `selfhst`, `dashboard-icons`, and `crypto`. Use `--limit 1` for a small shortlist: the cap is **per source**, so a successful broad search can return up to eleven matches. The CLI default remains ten per source; always set a small explicit limit when context matters. Use `--refresh` after a reported catalog update. JSON includes each source's lookup time, cache flag, commit where available, total matches, and failures. Cached catalogs expire after 24 hours; failures do not fall back silently to expired data. `--offline` uses only a full local checkout, regardless of `--source`.

GitHub's unauthenticated rate limit may affect upstream tree requests. Use the upstream website or an existing authenticated GitHub tool if that occurs. Do not send credentials to asset hosts. If an adapter format changes, inspect the linked upstream data and update the adapter; do not interpret a parser error as an absent brand.

The helper searches normalized names, filenames, and supplied aliases where the adapter supports them. Metadata is retrieved from the same commit as each source's asset tree. It does not use fuzzy matching, translate names, or resolve model-to-company relationships. Try spelling/parent-company aliases deliberately. Results link to a commit-pinned repository license; `repository_license` describes the project, not automatic trademark clearance. Original adapters also retain their existing `library_license` field for compatibility. Upstream licenses and notices may change; check the selected revision when redistributing files.

Gilbarbara Logos and selfh.st currently request new-icon suggestions via issues/discussions rather than external asset PRs. Cryptocurrency Icons also asks for requests through issues. Follow each upstream's contribution policy; our own contribution workflow does not override theirs.
